## Nullability and physical-contract rules

- If the ERD is silent, the CSV says NOT_SPECIFIED_BY_ERD; do not convert a type annotation into NOT NULL by assumption.
- PK semantics imply NOT NULL. Child name/slug/description/selling_price carry explicit inherit-on-NULL notes; cost_price is nullable.
- ERD does not mark ACCOUNTS.phone, ACCOUNTS.email or PRODUCTS.slug unique. D1/DB-09 must decide phone uniqueness.
- DDL draft is not MySQL-verified; P0 reported failing H2 status checks and no target MySQL run.
