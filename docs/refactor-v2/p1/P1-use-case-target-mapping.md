## Shared target invariants

- The approved target has 31 tables; do not re-add legacy Variant/SizeSystem/SizeValue/Color, persisted quote, stock reservation, voucher-scope/usage-ledger, payment/shipping-event or detailed return tables without an explicit owner amendment.
- Product IDs are used consistently by Cart, OrderItems, GoodsReceiptItems, Inventory and InventoryTransactions.
- Money is integer VND; apply order-level HALF-UP then largest-remainder line allocation with ascending Product ID tie-break.
- Owner approval closes the design-choice gate, not runtime acceptance. P1/P2 remains open until exact-SHA schema, module, security, rollback, concurrency and frontend tests pass.
- Numeric data/audit/image retention and anonymization exceptions remain TBD; do not purge automatically.
