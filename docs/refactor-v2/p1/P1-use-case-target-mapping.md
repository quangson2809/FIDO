## Global constraints carried into every UC

- Controllers never return JPA entities; business writes go through the owning module’s service.
- Actor identity is derived from authenticated context; totals, status transitions, timestamps and stock are server/database-owned.
- Target currency is VND and monetary storage/wire amounts are integer VND; discount rounding/allocation must be approved before any implementation claims exact reconciliation.
- The target is a single-merchant, COD-only, one-operational-warehouse v1 with manual shipping. Do not add guest checkout, payment gateway, automatic carrier integration, variant tables, persisted quote tables or return/refund event tables without an explicit owner amendment.
- Legacy state charts and old endpoint status columns are source evidence only. “Mapped” in the CSVs means documentation mapping, not implementation or acceptance.
- A UC passes only when its request/response/errors, authorization, data integrity, transaction behavior and relevant concurrency/rollback/replay tests all pass at an exact commit.
